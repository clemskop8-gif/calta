# Автообновление данных CALTA (курс валют, зерно, новости)

Курс валют на сайте уже обновляется сам — при каждом заходе браузер
дёргает бесплатный `open.er-api.com` напрямую, без ключа. Ничего
настраивать не нужно.

Зерно и новости требуют платных/ключевых источников, поэтому их нельзя
дёргать прямо из браузера (ключ был бы виден всем в коде страницы).
Решение: **GitHub Actions** сам, по расписанию, раз в сутки, ходит по
API с ключом, спрятанным в GitHub Secrets, и сохраняет результат в
`data/grain.json` и `data/news.json`. Сайт при загрузке просто читает
эти два файла — без ключей и без сервера.

```
GitHub Actions (каждый день, 05:00 UTC)
   → scripts/update_grain.py  → пишет data/grain.json
   → scripts/update_news.py   → пишет data/news.json
        │
        ▼
   git commit + git push (сам workflow)
        │
        ▼
   index.html при открытии делает fetch('./data/grain.json')
   и fetch('./data/news.json') — обычные статические файлы,
   ключей внутри нет
```

## Расписание — раз в 24 часа

Уже настроено в `.github/workflows/update-data.yml`:

```yaml
schedule:
  - cron: '0 5 * * *'   # каждый день в 05:00 UTC (~09:00 по Астане)
```

Если нужно другое время — поменяйте только час (второе число). Например,
`'0 21 * * *'` — каждый день в 21:00 UTC. Кроме расписания, workflow
можно запустить вручную в любой момент: вкладка **Actions → Update data →
Run workflow** на GitHub.

## Шаги настройки (один раз)

1. **Создайте репозиторий на GitHub** (можно приватный) и загрузите в
   него всё содержимое этой папки как есть (сохраняя структуру папок).

2. **Получите два бесплатных ключа:**
   - Alpha Vantage (котировка пшеницы): https://www.alphavantage.co/support/#api-key
     — бесплатно, лимит 25 запросов/день, для раза в сутки более чем достаточно.
   - Unsplash (фото для новостей): https://unsplash.com/developers
     — бесплатный тариф, до 50 запросов/час.

3. **Добавьте ключи в секреты репозитория:**
   Settings → Secrets and variables → Actions → New repository secret
   - `ALPHAVANTAGE_KEY` — ключ из шага 2
   - `UNSPLASH_ACCESS_KEY` — ключ из шага 2

   Ключи нигде не видны в коде и не попадают в публичный репозиторий.

4. **Включите GitHub Pages:**
   Settings → Pages → Source: **Deploy from a branch** → ветка `main`,
   папка `/ (root)`. Через пару минут сайт будет доступен по адресу
   вида `https://<ваш-логин>.github.io/<репозиторий>/`.

5. **Проверьте вручную**, не дожидаясь ночи:
   вкладка **Actions** → выберите workflow **"Обновление данных сайта
   (раз в 24 часа)"** → кнопка **Run workflow**. Через 1–2 минуты в
   папке `data/` появятся обновлённые `grain.json` и `news.json` с
   `"isDemo": false` — и на сайте сразу изменится котировка и новости.

## Про новостные ленты

В `scripts/update_news.py` в начале файла есть список `FEEDS` — сейчас
там два примера RSS-лент. Замените их на реальные интересующие вас
источники (любые открытые RSS по логистике/торговле/Центральной Азии) —
просто впишите новые URL в список, ключ не нужен, RSS — это всегда
бесплатно и без регистрации.

## Если что-то не подключено или временно недоступно

Оба скрипта написаны так, что **никогда не ломают сайт**:
- нет ключа / API недоступен → в JSON пишется `"isDemo": true` и
  прежние демонстрационные данные;
- сайт при `isDemo: true` показывает то же, что показывает сейчас
  (демо-котировку, карточки-образцы новостей с плейсхолдерами фото) —
  без ошибок и пустых мест.

## Про лимит Alpha Vantage (25 запросов/день)

Скрипт делает всего 1 запрос за прогон, а Action запускается 1 раз в
сутки — то есть используется 1 запрос из 25 в день. Есть большой запас
даже если вы будете иногда запускать workflow вручную для проверки.
